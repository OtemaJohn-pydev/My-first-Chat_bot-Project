# Simple LangChain-Groq Chatbot

A simple AI chatbot built with **Python, Streamlit, LangChain, and Groq**.

The application provides a conversational chat interface where users can send questions and receive responses from a Large Language Model (LLM). Conversation history is maintained during the Streamlit session.


## Features

- Interactive chat interface using Streamlit
- Powered by a Large Language Model through Groq
- Uses LangChain for LLM integration
- Maintains conversation history using Streamlit session state
- Uses environment variables for API configuration
- Configurable model and temperature
- Automatically updates the chat interface after each response


## Technologies Used

- **Python** – Programming language
- **Streamlit** – Web interface
- **LangChain** – Framework for building LLM applications
- **LangChain-Groq** – Integration between LangChain and Groq
- **Groq** – LLM inference platform
- **python-dotenv** – Environment variable management
- **uv** – Python project and dependency management
